# WHERE MYTH FADE TO LEGEND

## August 2026 — Indonesia Observatory

A monthly evidence-first observatory for mythos, ritual, religious context, media propagation, Tauhid Gap, and causality.

### Principles

- Allah is the theological reference point for the Tauhid lens used in this project.
- Religions, ethnic groups, and communities are not scored as good/bad.
- Specific practices are evaluated separately from people and institutions.
- Mythos, doctrine, tradition, ritual, and media narratives are kept distinct.
- Temporal correlation is not treated as causation.
- Evidence quality is scored independently from Tauhid Gap.

### Score definitions

**Evidence Score**: confidence in the factual documentation of an event/practice.

**Tauhid Gap Score**: comparative theological assessment of the documented practice against the project's Allah/Tawhid reference point. It is not a score of personal faith.

**Causality Score**: strength of evidence for a cause-and-effect relationship. Temporal proximity alone is insufficient.
