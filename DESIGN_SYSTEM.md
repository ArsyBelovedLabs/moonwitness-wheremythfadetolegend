# MoonWitness Design System Integration

This application consumes the canonical shared UI package from:

- `ArsyBelovedLabs/moonwitness-design-system`
- package: `@arsybelovedlabs/moonwitness-design-system`
- theme: `myth-fade`

## Boundary

The design-system owns semantic tokens, reusable visual primitives, instrument geometry, motion/accessibility contracts, and shared themes.

This repository continues to own all research data, domain behavior, routing, Leaflet data layers, monthly report logic, causality calculations, evidence/revelation content, and application-specific composition.

The integration intentionally does **not** modify the frozen August 2026 data files.

## Visual contract

The application maps its existing research surfaces onto the shared cinematic observatory language:

- obsidian instrument surfaces
- antique bronze rails
- restrained crimson signal states
- sharp/chamfered geometry
- evidence-ledger density
- map-rift presentation
- semantic focus and reduced-motion behavior

The research guardrail remains explicit:

> Temporal/geographic proximity does not establish causation.

Application-specific CSS may compose the shared semantic tokens, but reusable primitives should be promoted back into `moonwitness-design-system` instead of duplicated here.
