# Public Web Visual Fidelity Checklist v1

Status: ACTIVE / ISSUE #9 / W0-11 PRECONDITION

The primary public Web must align with the frozen MoonWitness visual constitution before W0-11 closeout.

## Authorized active surfaces
1. Monthly Report / Observatory Home Experience
2. Spread Map
3. Disaster Map
4. Correlation
5. Practice-Level Review
6. Evidence
7. Four Revelation Lens
8. Candidate Pipeline

No ninth Home route is introduced by this work.

## Required fidelity checks
- consume canonical `moonwitness-frontend-platform` public exports;
- use canonical 27-icon system, no local geometry forks;
- one dominant instrument per page;
- frozen historical state visibly distinct from live operational state;
- exact causality guardrail where relevant: `Temporal/geographic proximity does not establish causation.`;
- Disaster Map and observation Spread Map remain independent;
- Four Revelation Lens remains exactly four channels;
- practice review remains practice-level only;
- inspectors/drawers preserve parent route/filter/viewport context where practical;
- map has a textual/list alternative;
- keyboard/focus and non-color status semantics are verified;
- responsive composition verified at 1440, 1280, 1024, 768, 430, 390, and 360 widths;
- no horizontal overflow on mobile.

## Golden evidence
Golden images are validation/reference artifacts only. They cannot create data, routes, metrics, states, or component geometry. Figma remains the design master when present.

## Completion evidence
Record implementation/fidelity verification in `docs/GENESIS-W0-11-WORKER-REPORT.yaml` and link the final visual certification evidence before merging `dev -> main`.
